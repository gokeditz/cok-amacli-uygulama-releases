# Clawd Club

Clawd'un 3D gece kulübünde dans ettiği tek dosyalık sayfa. `index.html`'i tarayıcıda aç, yeter; internet gerekmez.

- **Sahne:** Three.js, yansıyan LED pist, hareketli spot ışıkları ve hacimli huzmeler, disko topu, LED ekran, seyirci, konfeti, bloom
- **Müzik:** Web Audio ile anlık sentezlenen 124 BPM house parçası (intro → groove → build-up → drop → break)
- **Dans:** 11 hareket; otomatik modda şarkının bölümüne göre koreografi ve kamera kurgusu kendiliğinden değişir

Kısayollar: `Boşluk` müzik · `0` otomatik · `1–9` hareket · `C` serbest kamera · `H` arayüzü gizle · `F` tam ekran · `↑↓` tempo

## Geliştirme

```sh
npm install
npm run build   # src/ → index.html
```
